# Hotel Booking Cancellation Analysis

An Excel dashboard project for exploring hotel booking activity and cancellation patterns across hotel type, guest type, arrival month, year, and room status.

## Project overview

This project uses hotel reservation data to summarize booking volume and cancellations, then compares patterns across key customer and property categories. The Excel workbook includes a booking data sheet, pivot analysis, and an interactive dashboard with year and arrival-month filters.

## Project objectives

- Summarize total bookings and cancelled bookings.
- Compare bookings and cancellations by guest type.
- Explore monthly booking and cancellation patterns.
- Compare City Hotel and Resort Hotel bookings and cancellations.
- Review booking outcomes by room status.
- Make it easier to explore the results using dashboard filters.

## Dashboard contents

The dashboard presents:

- Total bookings and total cancellations
- Booking and cancellation comparisons by guest type
- Monthly booking and cancellation trends
- City Hotel versus Resort Hotel comparisons
- Room status comparisons
- Filters for arrival year and arrival month

## Workbook structure

| Sheet | Purpose |
|---|---|
| `hotel_booking` | Booking-level source data |
| `Pivot` | Pivot-style summaries supporting the dashboard |
| `Dashboard` | Visual summary and interactive filters |

The source sheet contains 119,390 booking records and 27 fields, including cancellation status, arrival date information, guest counts, country, and reserved and assigned room types.

## Tools and techniques

- Microsoft Excel
- Pivot tables and summary metrics
- Interactive filters and dashboard navigation
- KPI summaries and categorical trend analysis
- Charts for comparing booking and cancellation patterns

## How to explore the workbook

1. Open the workbook in Microsoft Excel for the full dashboard experience.
2. Use the arrival year and arrival month filters to focus the dashboard.
3. Compare the guest type, hotel type, monthly, and room status views.
4. Review the `Pivot` and `hotel_booking` sheets for supporting summaries and source records.
